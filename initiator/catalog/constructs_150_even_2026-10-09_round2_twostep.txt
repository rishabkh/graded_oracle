Integer ALU: Selects among add, subtract, logical, and compare operations on two operands and produces a result plus condition flags held in a flag register.

Integer-to-float converter: Normalizes an integer into mantissa and exponent fields and rounds to the target format, keeping an optional output register.
NOR gate: Outputs the complement of the OR of its inputs, and holds no internal state.
One-hot AND-OR multiplexer: Combines inputs by ANDing each with its own bit of a one-hot select register and ORing the results into the output, holding only that one-hot select register.
Thermometer-to-binary encoder: Converts a thermometer-coded input vector into the binary count of its asserted lines, optionally latching the result in an output register.
JK flip-flop: Keeps one state bit that on each clock edge holds, sets, resets, or toggles according to the J and K inputs.
Johnson ring counter: Circulates a pattern through a shift register whose last bit is inverted back into the first stage.
Tapped delay line: Propagates a signal through a chain of buffers and exposes intermediate taps, with optional sampling flops on each tap.
Pausible clock controller: Stretches or pauses a local ring-oscillator clock while an asynchronous handshake is resolved by a mutual-exclusion element, keeping the clock-enable state and the handshake latch.
LIFO stack: Stores pushed words in a memory array addressed by a top-of-stack pointer register.
Read-modify-write RAM with bypass: A RAM that reads a word, applies an operation such as increment or OR, and writes it back, forwarding in-flight results to back-to-back accesses on the same address; it keeps the array, pipeline stage registers and a bypass address/data register.
Matrix tile register file: Holds two-dimensional tiles of rows by columns accessed row-wise for loads and stores and as whole operands by a matrix engine, keeping the tile data and a per-tile shape configuration register.

Latency-matched bank read multiplexer: Selects the read data of the memory bank that was addressed several cycles earlier, keeping a pipeline of delayed bank-select codes.
Mode register programming unit: Issues MRS/MRW commands that load CAS latency, burst length, ODT and drive-strength settings into the DRAM, keeping shadow copies of each mode register and a pending-update flag set.
Wear-leveling mapping table: Translates logical to physical blocks and records per-block erase counts in a mapping memory.
Trace cache: Stores dynamic instruction sequences that span taken branches as single lines, keeping per-line start address, branch outcome flags, instruction slots and the next fetch address.

Hardware semaphore block: Provides test-and-set lock cells that record the owning requester id and a locked flag per cell.
