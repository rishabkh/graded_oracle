# Only the safety half is here. Existence, unbounded Response and Chain
# Response are excluded because k-induction cannot prove liveness; that is
# a scope decision, stated, not an oversight.
#
# Weights are chosen, not inherited. Universality plus Absence come to 40%
# because a census of the two evaluation sets (34 riscv-formal checks, 109
# large_lemma_miners files) found both dominated by them. Precedence is
# raised because it is the riscv-formal reg-check shape, and Bounded
# Existence because 64% of the Technion hard files carry a counter bound.
# A guarded assertion is NOT a separate pattern: `if (g) assert (e)` is
# `assert (!g || e)`, which is still Universality. Repeated lines weight.
