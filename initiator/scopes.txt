# Dwyer's scopes: WHEN the property is required to hold. Each non-global
# scope costs one register, and each one changes the invariant too - an
# armed property is unprovable until the invariant ties the arm bit to the
# state it implies. That is exactly the shape of riscv-formal's reg check
# (register_written latches once, register_shadow holds the value, and the
# property only then compares them), which is in the problem set for all
# three cores and which our old corpus produced only by accident, in 9 of
# 173 designs.
#

# same property with a stronger antecedent, evaluated fresh every cycle.

# share of the rest because it is the riscv-formal shape.
