# How the assertion is WRITTEN, as opposed to what it means (patterns.txt).
# Only forms the open-source yosys frontend actually parses and proves are
# here: each was tested with a true version that must pass and a false
# version that must fail.
#
# Weighted by the same census: the evaluation sets are dominated by bare and
# guarded assertions. $past, $rose and $stable appear in neither set, so they
# are a small minority here - enough to teach reading, not enough to crowd
# out the forms that matter. The clocked property-block syntax that the
# Technion files use cannot be generated at all (yosys rejects it); those
# prompts are produced later by rewriting a proven design and re-checking it
# with EBMC.
#
